❓ Dúvidas Frequentes

Como adicionar uma tarefa?

Digite a descrição da tarefa no campo de entrada e clique em "Adicionar Tarefa" ou pressione Enter no teclado.

Como marcar uma tarefa como concluída?

Clique no botão verde "Concluir" na tarefa. Para reabrir, clique em "Reabrir".

Como editar uma tarefa?

Clique no botão azul "Editar", edite o texto na caixa que aparecer e clique OK.

Como remover uma tarefa?

Clique no botão vermelho "Remover" para deletar a tarefa permanentemente.

Minhas tarefas são salvas?

Sim! Suas tarefas são salvas automaticamente no navegador. Elas permanecerão mesmo após fechar a página.

Como definir prioridade e data de vencimento?

Use o menu suspenso para escolher a prioridade (Alta, Média, Baixa) e o campo de data antes de clicar em "Adicionar Tarefa". Cada tarefa exibirá essas informações.

Como filtrar minhas tarefas?

Use os botões de filtro no topo: "Todas", "Pendentes", "Concluídas" ou filtre por prioridade (🔴 Alta, 🟡 Média, 🟢 Baixa).

Como usar a busca?

Digite no campo "🔍 Buscar tarefas..." para encontrar tarefas rapidamente. A busca funciona em tempo real!

Como trocar de tema (claro/escuro)?

Clique no botão 🌙 (tema escuro) ou ☀️ (tema claro) no canto superior direito do cabeçalho.

Como exportar meus dados?

Clique no botão 📥 no cabeçalho. Um arquivo JSON com todas as suas tarefas será baixado.

Quais são as estatísticas que vejo?

Os cards mostram: Tarefas Pendentes, Tarefas Concluídas, Taxa de Conclusão (%) e Total de Tarefas.
